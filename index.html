Featured · final-year project

NGX Volatility Prediction System

A machine-learning system that predicts volatility for stocks on the Nigerian Exchange, with an interactive analytics dashboard. It forecasts how much stocks swing rather than trying to predict their price, and explains its predictions with SHAP.

PythonXGBoostRandom ForestSVRSHAPStreamlit
Read the case study
Problem
Investors and analysts need a view of risk, and volatility is a more forecastable quantity than price.
Data
Daily OHLCV history, 2020–2025, for fifteen NGX stocks across banking, telecoms and technology.
Models
Ridge Regression, Random Forest, XGBoost and Support Vector Regression, plus GARCH-related experiments.
Evaluation
RMSE and R² per stock. Results differ by stock, so no single score describes the whole system.
Interpretability
SHAP shows which features drive the tree-based models’ forecasts, so the output is not a black box.
Application
A Streamlit interface for exploring forecasts. I have not published a live link here.
